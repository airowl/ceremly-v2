## Landing Page (index.vue)

### Overview
Ceremly landing page — single-page Tailwind design for RSVP management platform.
Manages event confirmations via Email 1-click and WhatsApp Deep Links.

### Current Implementation
- **File**: `app/pages/index.vue`
- **Layout**: `false` (standalone, no shared header/footer)
- **Auth**: Disabled (`auth: false`)
- **Approach**: Pure Tailwind CSS (no Nuxt UI components)
- **Icons**: Google Material Symbols Outlined (loaded via `useHead`)
- **Font**: Manrope (via `@nuxt/fonts`, configured in `main.css`)

### Design System
- **Primary**: Light Bronze `#d4a373` (CSS variable `--color-primary-500`)
- **Secondary**: Tea Green `#ccd5ae` (CSS variable `--color-secondary-500`)
- **Accent colors**: Beige `#e9edc9`, Cornsilk `#fefae0`, Papaya Whip `#faedcd`
- **Background**: Smoke White `#FAF9F6` (`--ui-bg`)
- **Subdued text**: `text-primary-700` (#96622e)
- **Theme file**: `app/assets/css/main.css`

### Sections
1. **Navbar** — Sticky, logo + nav links + locale switcher (IT/EN) + auth link + CTA button
2. **Hero** — Headline, subtitle, dual CTAs, social proof (avatars + stars), mockup cards (WhatsApp/Email notifications)
3. **Waitlist Hero CTA** — Gradient banner with email form, honeypot anti-spam, UTM tracking
4. **Features** — 3 cards (Email 1-click, WhatsApp Deep Link, Social Proof Dinamico)
5. **Dashboard Section** — Mockup with event stats (confirmed/waiting/declined bars)
6. **WhatsApp Section** — Phone mockup showing chat with Deep Link flow
7. **Pricing** — 3 dynamic plans from `usePricing()` API (Starter/Pro/Agency)
8. **Final CTA** — Email form with waitlist signup
9. **Footer** — Logo, legal links, locale dropdown, copyright

### Composables Used
- `useI18n()` — All text via `t('landing.xxx')` keys
- `useSiteMode()` — `shouldShowAuthLinks` for conditional sign-in link
- `usePricing()` — `plans`, `getFormattedPrice()` for dynamic pricing
- `useToast()` — Toast notifications for form submissions
- `useSeoMeta()` — SEO meta tags

### Waitlist Form Integration
- **API endpoint**: `POST /api/waiting-list/subscribe`
- **Validation**: Zod schema (`z.string().email()`)
- **Anti-spam**: Honeypot field (`website`), timestamp check (`_t`)
- **Analytics**: Captures `referrer`, `utm_source`, `utm_medium`, `utm_campaign`
- **Duplicate handling**: Shows warning toast if email already subscribed
- **Two form locations**: Waitlist Hero section + Final CTA section (shared state)

### i18n
- **Translation keys**: `landing.*` in `i18n/locales/it-IT.json` and `en-US.json`
- **Subsections**: nav, hero, waitlistHero, features, dashboard, whatsapp, pricing, finalCta, landingFooter, howItWorks, forWho, trust, why, faq, waitingList, contact, newsletter
- **Pricing plan keys**: `landing.pricing.tiers.{free|basic|pro}.*`
- **Feature keys**: `plan.{free|basic|pro}.*` (from `usePricing` composable)

### Pricing Integration
- Plans fetched from `/api/pricing/plans` via `usePricing()` composable
- Fallback: free ($0), basic (900 cents), pro (2900 cents)
- Plan IDs map: `free` → Starter, `basic` → Pro, `pro` → Agency
- Features listed from `PLAN_CONFIGS` in `server/config/planLimits.ts`
- Price formatting via `getFormattedPrice(planId, billingCycle)`

  - `defineWebPage()` — page-level metadata (Organization/WebSite inherited from app.vue)

- `defineArticle()` with `@type: BlogPosting` — headline, description, datePublished, author, image, keywords ✅

#### Sitemap & Robots
- Sitemap via `@nuxtjs/seo` bundled `@nuxtjs/sitemap` ✅
- Auto-discovery of routes from `pages/` directory ✅
- i18n support via `autoI18n: true` ✅
- Excluded routes: `/dashboard/**`, `/login`, `/signup`, `/invite/**`, `/maintenance`, `/legal/**`
- Dynamic `robots.txt` via `@nuxtjs/robots` (replaces static `public/robots.txt`) ✅
- Malicious bot blocking: sqlmap, nikto, masscan, nmap disallowed ✅
- Sitemap URL auto-appended by robots module ✅

#### Architecture Notes
- Base URL from `site.url` in nuxt.config (env: `NUXT_PUBLIC_BASE_URL`)
- Fallback base URL: `https://ceremly.it`
- OG images must be 1200x630px for optimal social preview
- JSON-LD managed declaratively via `nuxt-schema-org` composables
- Landing page overrides app.vue default title with `titleTemplate: ''`
- `schemaOrg.identity` in nuxt.config defines Organization globally

### Security
- No authentication required (public page)
- Honeypot anti-spam on waitlist form
- Rate limiting via server middleware
- No sensitive data exposed

## Maintenance Page (maintenance.vue)

### Overview
Static maintenance page displayed when site is in maintenance mode.

### Current Implementation
- **File**: `app/pages/maintenance.vue`
- **Layout**: Uses custom `maintenance` layout
- **Auth**: Disabled (`auth: false`) - required for SSR prerendering
- **Prerender**: Enabled in nuxt.config.ts

### Components Used
- `MaintenanceHeader` - Custom header for maintenance mode
- `LandingNewsletterCTA` - Newsletter signup (waiting list)
- `LandingAppLogo` - Site logo
- Nuxt UI components: `UContainer`, `UCard`, `UBadge`, `UButton`, `UIcon`

### Features
- i18n support (Italian and English)
- SEO meta tags
- Feature preview cards
- Stats display (uptime, support, response time)
- Newsletter/waiting list signup
- Contact information

### Route Rules (nuxt.config.ts)
```typescript
"/maintenance": { prerender: true }
```

### Middleware Behavior
- `0.site-mode.global.ts`: Skips on server-side (`process.server`)
  - In maintenance mode: redirects all routes to `/maintenance`
  - Not in maintenance mode: redirects `/maintenance` to `/`
- `auth.global.ts`: Disabled for this page via `auth: false`

### Architecture Notes
- Page must have `auth: false` to allow SSR prerendering
- Auth middleware makes `fetchSession()` calls that fail during prerender
- Site mode is controlled via `NUXT_PUBLIC_SITE_MODE` env variable
